# 📚 Livraria Virtual

Uma livraria digital completa com sistema de vendas, PDF, comprovantes e aprovação de pagamentos.

## 🚀 Funcionalidades

- ✅ Catálogo de livros com busca e filtros
- ✅ Visualização de PDF (com zoom e sem download)
- ✅ Sistema de compras com comprovante
- ✅ Aprovação de pagamentos pelo admin
- ✅ Download do livro após aprovação
- ✅ Painel administrativo completo
- ✅ Livros gratuitos e pagos

## 🛠️ Tecnologias

- **Backend:** Python + Flask + SQLite
- **Frontend:** HTML5, CSS3, JavaScript
- **Banco de Dados:** SQLite

## 📦 Instalação

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/livraria-virtual.git
cd livraria-virtual

# Instale as dependências
pip install -r requirements.txt

# Execute o servidor
python app.py
